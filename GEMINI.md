# Catalyst Solo AI Hackathon — Project Rules & Guidelines

## 1. Scope & Execution Boundary
- Work exclusively inside this project workspace (`Catalyst_Hackathon_2026`).
- Do not read, create, or modify files outside of this project folder.

## 2. Git & Version Control
- Operate on a single Git branch named `main`.
- Never create additional local or remote Git branches.
- Never push code to GitHub or any remote repository without explicit user approval.
- Keep the final GitHub repository size under 10 MB (exclude unnecessary build artifacts, caches, virtual environments, large binary assets, and dependencies via `.gitignore`).

## 3. Data Confidentiality & Security
- Strict Zero Confidential Data Policy: Never reference, incorporate, mock, or store proprietary company or Walmart data, credentials, or internal references.

## 4. Development Principles
- Prioritize working, rigorously tested, and practical solutions over speculative architecture.
- Follow lean dependency management to stay within size and complexity limits.

## 5. Hackathon Phase Constraint
- Do NOT generate application code or start implementation until the official hackathon challenge statement has been provided and confirmed by the user.
